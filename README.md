# Учебная практика ПМ.01

Учебно-методический комплект для профессии **09.01.05 «Оператор технической поддержки»**: ПМ.01 «Поддержка клиентов по вопросам эксплуатации технологических компонентов».

- организация: Университет «Синергия»;
- учебный год: 2026;
- семестр: 1;
- среда: автономный браузерный стенд;
- предметные области: 30 содержательных вариантов и отдельная демонстрационная область.

В `site/downloads/` также находятся автономный учебный сервис, демонстрационные данные, выполненный демонстрационный результат и отдельный JSON для каждого варианта. Все данные учебные и обезличенные.

## Проверка

```sh
python scripts/build.py
python scripts/check.py
```

`build.py` формирует контрольный манифест уже подготовленного статического комплекта. `check.py` проверяет паспорт, число вариантов и заявок, внутренние ссылки, PDF, DOCX, архивы, прямые ссылки каждого варианта и отсутствие запрещённых элементов.

Публикация GitHub Pages выполняется workflow `.github/workflows/pages.yml` только из ветки `main`.
